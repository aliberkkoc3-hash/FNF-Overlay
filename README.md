# FNF Overlay

A customizable overlay tool for **Friday Night Funkin'**, developed by **Prism Crew**.

FNF Overlay aims to provide a lightweight, simple, and convenient experience for players who want additional on-screen information while playing.

## Features

- Lightweight design
- Customizable overlay experience
- Simple and easy-to-use interface
- Configuration support
- Built with C#

## Installation

1. Visit the [Releases](https://github.com/aliberkkoc3-hash/FNF-Overlay/releases) page.
2. Download the latest release.
3. Extract the downloaded files if necessary.
4. Run `FNFOverlay.exe`.

## Building from Source

1. Clone this repository:

   ```bash
   git clone https://github.com/aliberkkoc3-hash/FNF-Overlay.git
   ```

2. Open the project folder.
3. Run `B.bat` to build the application, if the build script is included.
4. The compiled executable will be generated according to the build script's configuration.
